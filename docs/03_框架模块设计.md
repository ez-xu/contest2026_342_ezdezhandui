## 三、模块设计

### 3.1 启动链路（SIMPLE_BOOT，已完成）

```
ROM（flash 0x2000 加载 ram-only 镜像）
  → __start（关中断/设栈）
  → __esp_start（mtvec/mtvt 配置 → bss 清零 → CLIC 全禁用 → bootloader_init）
  → nx_start（SMP 双核调度器）
  → nsh / ai_agent
```

关键修复（4 处根因）：
1. `flat_memory.ld`：SIMPLE_BOOT 条件 + rev3 `sram_seg`（代码全 SRAM）
2. 烧录偏移 0x2000（P4 BL_OFFSET）+ esptool ≥4.12
3. `esp_start.c`：SIMPLE_BOOT 跳过 `map_rom_segments`（XIP 污染）
4. `esp_start.c`：早期禁用全部 CLIC 中断（风暴）

### 3.2 Console（USB-Serial / UART0）

- 驱动：`esp_usbserial.c`（USB-Serial/JTAG 外设 0x500D2000）或 `esp_serial.c` UART0（GPIO37/38）
- 中断链：外设 INT_ENA → 路由矩阵 → CLIC → riscv_doirq → irq_dispatch
- **当前卡点**：CLIC 使能位图寄存器机制（坑 8——待对照 ESP-IDF）

### 3.3 网络（EMAC）

- 驱动：`esp_emac.c`（esp_eth 栈——MAC+PHY+SMI）
- 引脚（官方默认 V1.5.2）：MDC=GPIO31 / MDIO=GPIO52 / RMII_CLK=GPIO50 / PHY_ADDR=1
- 依赖：NET + IOB_NCHAINS + riscv_netinitialize（已补）
- **当前卡点**：esp_eth_mac_new_esp32 初始化失败（需 console 日志）

### 3.4 ai_agent（MiMo）

- 包：`packages/ai_agent`（openvela 官方——goldfish 已验证）
- 配置参考：`defconfigs/esp32s3-eye/`（同类芯片预设）
- 依赖：网络 + mbedTLS（HTTPS）+ CJSON + DNS
- **当前卡点**：mbedTLS 配置链（MD_C 等 Kconfig 缺失）

### 3.5 语音/摄像头（P1，待开发）

- ES8311 codec：I2C 配置 + I2S 数据（板载 MIC/SPK）
- MIPI-CSI 2MP：摄像头事件主动（视觉感知）

## 四、关键机制

| 机制 | 说明 |
|---|---|
| SIMPLE_BOOT（ram-only）| 镜像仅 RAM 段（0x4FF40000），ROM 从 flash 0x2000 加载 |
| 中断体系（CLIC）| 硬件向量中断（mtvt），每中断 intctl 优先级 |
| 文件树移植 | 公版 + 适配分层（git 4 提交结构：公版/xml/适配/文档）|
| deploy/export | 作品仓 ↔ 工作区双向同步（防漂移）|
| 日志归集 | contest-log-collector（会话日志 → logs/）|
| JTAG 调试 | OpenOCD halt/load_image/resume + 内存读取（console 未通时验证手段）|

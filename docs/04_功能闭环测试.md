## 一、测试体系（四层）

```
L1 构建验证    cmake 构建 + 产物检查（nuttx.bin/ELF 段布局）
L2 烧录验证    esptool 烧录（0x2000）+ 读回校验 + JTAG 加载
L3 运行验证    NuttX 启动（banner/调度器）+ 内存/寄存器状态（JTAG）
L4 功能闭环    外设功能 → 交互命令 → 结果验证（console 就绪后）
```

**回环定义**：提交（文件树）→ deploy → 构建 → 烧录/加载 → 运行 → 验证 → 记录

## 六、验证命令速查

```bash
# L1 构建
export PATH="$PWD/prebuilts/gcc/linux-x86_64/riscv-none-elf/bin:$PWD/prebuilts/build-tools/linux-x86_64/bin:$HOME/.local/bin:$PATH"
cmake -S nuttx -B cmake_out/esp32p4-function-ev-board_nsh -G Ninja \
  -DBOARD_CONFIG=boards/risc-v/esp32p4/esp32p4-function-ev-board/configs/nsh
cmake --build cmake_out/esp32p4-function-ev-board_nsh -j8

# L2 烧录（P4 偏移 0x2000）
esptool.py --chip esp32p4 --port /dev/ttyACM0 write_flash 0x2000 cmake_out/.../nuttx.bin

# L2/L3 JTAG 加载调试
export OPENOCD_SCRIPTS=/tmp/openocd-esp32/openocd-esp32/share/openocd/scripts
openocd -f board/esp32p4-builtin.cfg -c "init" -c "halt" \
  -c "load_image cmake_out/.../nuttx" -c "resume <entry>" -c "sleep 6000" -c "halt"

# L3 内存验证（halt 后）
openocd ... -c "mdw <addr> <n>"   # 读中断表/bss/外设寄存器

# 串口监听（自动重连，设备复位循环时）
for i in $(seq 1 30); do [ -e /dev/ttyACM0 ] && timeout 6 cat /dev/ttyACM0; sleep 1; done
```

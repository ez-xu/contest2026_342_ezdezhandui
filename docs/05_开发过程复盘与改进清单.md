### 阶段 6：ai_agent 固件 SRAM 裁剪（8/26–27，踩坑笔记 #03 更新）——512KB 硬约束攻坚
- **PSRAM-rodata 方案证伪**：P4 ROM bootloader 不初始化 PSRAM（需 PMU/EXT_LDO/MPLL/MSPI/L2 cache/MMU 全套 bring-up，只能由二级 bootloader 做）→ 0x48000000 段 ROM 拷贝必失败 → 回退 esptool DROM_MAP patch + 链接脚本 + defconfig SPIRAM
- **PMP 根因链（三次重启级故障）**：
  1. bss 越过 0x4FFC0000 → ROM 锁定的 PMP 写保护 → store fault（旧固件 bss 小没触发）
  2. 错误假设"清 PMP 可解"→ `csrw pmpcfg0` 在 P4 上非法指令（ePMP 机制），且 ROM 锁定位不可清
  3. 误扩窗口到 [0x4FF00000, 0x4FFC0000) 768KB → [0x4FF00000, 0x4FF40000) 是 L2 cache 存储区，复位即清零 → 固件被抹掉
  4. **最终解**：窗口锁定 [0x4FF40000, 0x4FFC0000) 512KB（PMP RW 区 + 非 cache 存储），`CONFIG_ESPRESSIF_REGION_PROTECTION=n`（NuttX 自配 PMP 会写保护 0x4FFC0000+）
- **make 路径 ≠ CMake 路径（本阶段最大教训）**：早期用 CMake 验证的修复（riscv_mtimer 条件编译、esp32p4_atomic.c、appinit、HAL patches）在 make 构建路径全部缺失 → 补 Make.defs/Unix.mk 对齐；HAL re-clone 清手工改动 → 固化 0001/0002 patch 并接入 make clone 步骤
- **裁剪组合拳（613KB → 438KB）**：ostest/getprime 关、mbedTLS 深剪（PSA/DTLS/SHA512/DES/SHA3/ERROR 字符串/GENPRIME/cipher 模式）、ai_agent 非核心模块门控（voice/web_search/media/vision/shell/cron，weak stub 保链接）、IOB_NBUFFERS 8、LIBC_FLOATINGPOINT 关
- **致命约束发现**：esptool `merge_adjacent_segments` 只合并 VMA 连续段；ROM 按 segment 动态设 PMP WX 边界 → **text 段必须连续**（把 .flash.text 移到 .iram0.text 之后）
- **结果**：nuttx.bin = 448,528 B（437.8KB），6 段全在 [0x4FF40000, 0x4FFC0000)，ROM 接受并跳转，**固件首次跑进调度器 idle（wfi）**，PMP 全通

### 阶段 7：console 打通攻坚（8/27）——目标 NSH 交互
